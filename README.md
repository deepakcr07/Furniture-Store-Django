# Furniture Store - Django E-commerce Website

## Overview

A full-stack Furniture Store web application developed using Django.

The application allows users to browse furniture products, manage shopping carts, place orders, and administrators to manage products through Django Admin.

---

## Features

- User Registration & Login
- Product Listing
- Product Details
- Shopping Cart
- Checkout (Cash on Delivery)
- Order History
- Django Admin Dashboard
- Product Image Upload
- Responsive Design

---

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript

---

## Installation

Clone repository

```bash
git clone <repository-url>
```

Install packages

```bash
pip install -r requirements.txt
```

Run migrations

```bash
python manage.py migrate
```

Start server

```bash
python manage.py runserver
```
